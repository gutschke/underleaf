## Legend

- **Fire-by**: the arc window where the hook should pay off. `Ep N` = specific episode; `Act I early / mid / late` = phase-relative; `Act III sub-phase N` = per big-arc.md; `never / closing image` = intentionally held forever.
- **Status**:
  - `seeded` — planted, not yet fired
  - `partially fired` — some payoff has occurred, more to come
  - `fired` — main payoff has landed at the table
  - `carrying` — payoff is arc-recurring (e.g., misdirection texture)
  - `overdue` — past its fire-by; needs promote-or-retire decision this planning cycle
- **Source**: `dm/what-the-dm-holds.md` section number where the answer is held, or file path for older episodes.
